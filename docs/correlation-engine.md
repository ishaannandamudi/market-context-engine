# Correlation and systemic co-movement (MCE-7)

`CorrelationFeatureEngine.compute(store, as_of_ns)` produces continuous dependence evidence from the configured source and point-in-time `UniverseProvider`. The default provider uses `features.correlation.universe`, initially empty. `UniverseMembership.effective_from_ns` is inclusive, `effective_to_ns` is exclusive, and `available_at_ns` gates when a membership or weight becomes knowable. Historical endpoints request their own membership; today's constituents or weights never replace past ones. Optional sector summaries use a point-in-time `SectorUniverseProvider`, or the configured static `features.sectors.groups` when no sector provider is supplied. Nonexclusive sector assignment is withheld as ambiguous.

## Returns and alignment

All times are UTC nanoseconds. Only source-matching, positive-close, completed bars inside the XNYS regular session and effectively available by the explicit clock are considered. Intraday returns require exact `bar_cadence_ns` bars on a grid anchored at exchange open. At endpoint `t`, `r_i,t = ln(close_i,t / close_i,t-cadence)`. Both adjacent completed bars must exist in the same regular session. A gap removes its two adjacent return endpoints; nothing is forward filled or set to zero. A future bar end or effective time cannot enter an earlier result. Positive rescaling of all prices leaves returns unchanged.

`short_window_bars`, `medium_window_bars`, and `long_window_bars` default to 30, 60, and 120 **return endpoints**. Each needs one earlier close, so the first complete window needs 31, 61, or 121 completed cadence bars. Windows end at the latest completed grid slot at or before `as_of_ns` and never cross overnight. The medium window is the primary matrix and headline score. Optional `daily_horizons_sessions` use N log returns between exact completed XNYS session closes, requiring N+1 closes. A close is a full-session bar or exact final cadence bar. Before today's regular close, the most recent completed session is the previous trading day. Daily horizons are separate typed records and must meet `minimum_aligned_samples` (default 8).

Each window excludes symbols lacking a current endpoint return, with inadequate individual coverage, or with constant returns. A missing latest bar with earlier bars is stale; an entirely absent series or missing immediate close reference is missing. An intraday bar older than `freshness.bar_limit_ns` is stale. Daily closes must be at an exact session end; minute freshness is not applied to completed daily horizons. Retained symbols use the **intersection** of return timestamps. A series constant on that intersection is removed and alignment repeats. `symbol_coverage = matrix_dimension / expected_symbol_count`; `time_coverage = aligned_sample_count / expected_observations`. Matrix output needs `minimum_symbols` (default 3), `minimum_aligned_samples` (default 8), and `minimum_time_coverage` (default 0.8). The systemic score additionally needs `minimum_symbol_coverage` (default 0.8). Unavailable values are `None`. Typed output reports expected, valid, missing, stale, and constant symbols; `valid_symbols` means symbols retained in the primary matrix.

## Matrix and summary formulas

Let `X` be the `T × N` common-sample log-return matrix, with rows as timestamps and columns in sorted symbol order. Sample covariance is `S = (X - column_mean)ᵀ(X - column_mean)/(T-1)`; zero-variance columns are unavailable. Pearson correlation is `R_ij = S_ij/sqrt(S_ii S_jj)`. The public matrix consists of immutable tuples with sorted symbols, finite values, a unit diagonal, and symmetry. A common-sample covariance is positive semidefinite by construction; normalization preserves this within floating-point tolerance. The engine checks PSD. Pairwise deletion is never used for the primary matrix or eigenanalysis.

The separate Spearman matrix applies covariance/correlation to column ranks, giving **average ranks to ties**. It is available when `robust_estimator_enabled` is true and ranks are nonconstant; it does not replace Pearson. Identity shrinkage is `R_shrunk = (1 - α)R + αI`, with `α = shrinkage_strength` (default 0.1). This preserves unit diagonal and PSD. It is simple fixed shrinkage, **not** Ledoit–Wolf. Raw Pearson drives pairwise summaries, weighting, sector summaries, and clustering; shrunk Pearson drives eigen diagnostics.

The `N(N-1)/2` distinct off-diagonal raw Pearson entries give `average_pairwise_correlation = mean(R_ij)`, `median_pairwise_correlation = median(R_ij)`, and `correlation_dispersion = population_std(R_ij)`. Raw correlations remain in `[-1,1]`; correlation dispersion is a spread of **pairwise correlations**, not cross-sectional return dispersion. `spearman_average` is the off-diagonal mean of the rank matrix. When every current universe weight exists, total weight is positive, and retained weight/total weight meets minimum symbol coverage, weighted correlation is `Σ_(i<j) w_i w_j R_ij / Σ_(i<j) w_i w_j`. A zero pair-weight denominator makes it unavailable. `weight_coverage` is retained/total weight. No weights are inferred.

If `λ_1 ≥ … ≥ λ_N ≥ 0` are eigenvalues of `R_shrunk`, `largest_eigenvalue = λ_1`, `first_eigenvalue_share = λ_1/N`, and `effective_dimension = (Σλ)²/Σλ²`. The eigenvalue sum is N; share is in `[1/N,1]` and effective dimension in `[1,N]`, up to numerical tolerance. `market_mode_strength = clip((first_eigenvalue_share - 1/N)/(1 - 1/N), 0, 1)`. This is a minimal eigen diagnostic, not a PCA factor model.

`systemic_co_movement_score` has a positive-correlation gate. Let `p = max(0, average_pairwise_correlation)` and `m = market_mode_strength`. Then `score = p × (score_weights.average + score_weights.market_mode × m)` with nonnegative weights summing to one (defaults 0.5/0.5). Strongly negative average correlation cannot score as strong **positive systemic co-movement** solely because of a large leading eigenvalue. Contributor terms are exactly `w_average × p` and `w_mode × p × m`, and sum to the score. This is descriptive evidence, not a regime or trading signal.

## Historical and sector diagnostics

`correlation_acceleration = short_correlation - medium_correlation` compares nested current windows. `correlation_change = current_medium - previous_cadence_medium`, using the previous clock's own membership. `session_change` and `five_session_change` subtract medium-window correlation at exactly the preceding or fifth preceding trading-session **close**; a missing session does not shift the fifth-session position. The historical baseline contains only prior session-close medium correlations, each computed using its own causal bars and membership. `correlation_percentile = (count(prior < current) + 0.5 count(prior = current))/N` requires `minimum_baseline_samples` (default 10). `correlation_robust_z = (current - median(prior))/(1.4826 × MAD(prior))`; when MAD is zero it is zero only if current equals the median, otherwise unavailable. Baseline length defaults to 20 sessions; zero disables it. A current or future observation never enters its own baseline. Comparing a current intraday window with prior close windows is sensitive to time of day; MCE-16 offers separate same-bucket normalization of a supplied correlation context.

For each pair with unambiguous current sector assignments, `SectorPairCorrelation(first, second, pair_count, average)` reports raw Pearson mean. `within_sector_correlation` pools all same-sector constituent pairs; `cross_sector_correlation` pools different-sector pairs. Both need at least one pair; `within_cross_spread = within - cross` needs both. These are not sector-composite returns or sector strength. Optional deterministic complete-link grouping walks symbols lexically and assigns each to the first group for which **every** existing member satisfies `R_ij ≥ cluster_correlation_threshold` (default 0.7). `correlation_distance = sqrt(2(1 - clip(R_ij,-1,1)))` ranges from zero to two. Groups are descriptive threshold clusters, not regimes or a graph model.

## Quality and projection

Membership quality scales `evidence_quality = symbol_coverage × time_coverage × membership_factor`, with GOOD 1, DEGRADED/UNKNOWN 0.5, POOR 0.25, and UNUSABLE 0. Missing or stale symbols, inadequate aligned history/coverage, degraded membership, and unavailable baseline set existing flags. Evidence quality describes input quality, not prediction confidence. A valid matrix may remain visible when low coverage withholds the systemic score. Snapshot projection writes `correlation_score` and finite `correlation.*` scalars, combining flags, quality, and contributors with any existing snapshot. It leaves categorical correlation and market regimes `UNKNOWN`. Snapshot schema is 1.0; the engine version tracks the package release.

Stable scalar names are `correlation.average`, `.median`, `.weighted_average`, `.dispersion`, `.spearman_average`, `.short`, `.medium`, `.long`, `.acceleration`, `.change`, `.session_change`, `.five_session_change`, `.percentile`, `.robust_z`, `.first_eigen_share`, `.largest_eigenvalue`, `.effective_dimension`, `.market_mode`, `.systemic_score`, `.within_sector`, `.cross_sector`, `.within_cross_spread`, `.symbol_coverage`, `.time_coverage`, `.weight_coverage`, `.expected_symbols`, `.valid_symbols`, `.aligned_samples`, `.matrix_dimension`, `.cluster_count`, `.evidence_quality`, and optional `correlation.horizon.<N>d`. Unavailable values are omitted, not zero. Full matrices and groups remain in typed results; snapshots stay scalar.

This MCE-7 engine does not internally normalize intraday seasonality or implement nonlinear tail dependence, categorical regimes, or trading behavior. Later MCE-8, MCE-15, and MCE-16 packages add separate dispersion, graph, and session-relative context without changing its raw formulas. Correlation can be high in calm or volatile markets; volatility, breadth, trend, and sector strength remain separate evidence. A historically accurate membership feed and sufficient causal store capacity are essential. Evicted history lowers coverage rather than being reconstructed from future data.
