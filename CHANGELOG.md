# Changelog

## 1.0.0 — MCE-20

Completed the planned MCE-1 through MCE-20 roadmap. Added deterministic end-to-end snapshot/replay orchestration, a validated dependency DAG, request-scoped membership reuse, causal source lineage and snapshot fingerprints, stage timing and quality diagnostics, a bounded local service/API, explicit-input CLI export, integrated causality tests, and a consolidated profile. The snapshot, statistical feature, options context, and macro context schemas remain 1.0. Existing feature mathematics and provider-neutral contracts remain intact. The release is descriptive research infrastructure; it has no trading or execution functionality.
